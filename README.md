# Aura Battle v1

A scissors-paper-stone web game with Gen Alpha energy: aura points, brainrot commentary and 6-7 moments.

## Play

Open `index.html` in any browser. No install or build step.

## Features

- **Streak run**: one loss ends the run, ties keep your streak. Best streak is saved in the browser.
- **First to 7**: classic match mode, with a special moment when the score hits 6-7.
- **NPC Bot**: follows a readable habit (Copycat, Counter-puncher, Win-stay lose-switch, The Cycle, Stubborn) and switches every 7 rounds.
- **Sigma Bot**: learns your patterns and counters them.
- **Aura shop**: Third Eye (150), Shield (250), Scout (300).
- **Round history** to study the bot's habits.
- Keyboard: `1` scissors, `2` paper, `3` stone. Type `6` then `7` for a surprise.
